Task 2: FAQ Chatbot

📌 Project Overview

The FAQ Chatbot is an AI-powered application that answers frequently asked questions automatically. It compares a user's question with a predefined collection of questions and returns the most relevant answer.

🎯 Objectives

- Automate responses to frequently asked questions.
- Match user queries with relevant FAQ entries.
- Reduce the need for manual responses.
- Provide a simple conversational interface.

🛠️ Technologies Used

- Python
- Natural Language Processing (NLP)
- Scikit-learn
- TF-IDF Vectorization
- Cosine Similarity

⚙️ Features

- Accepts questions from users.
- Searches a predefined FAQ dataset.
- Uses text similarity to find relevant answers.
- Provides a fallback response when no suitable answer is found.

🚀 How to Run

1. Clone this repository.
2. Install the required Python libraries.
3. Run the Python script or application.
4. Enter a question and view the chatbot's response.

📚 Learning Outcomes

- Understanding basic chatbot development.
- Learning text preprocessing and vectorization.
- Applying TF-IDF and cosine similarity.
- Building a simple AI-based question-answering system.
